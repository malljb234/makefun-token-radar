Token Radar ranks 178 pre-token protocols by implied value using the radar-2 model (TVL, growth, maturity, breadth, category multiple) and serves a sortable, filterable dashboard with per-protocol detail views and 6-step farm plans.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
